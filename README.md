# 📊 Power BI Shipment & Sales Analytics Dashboard

## 📌 Project Overview

This project is an interactive **Power BI dashboard** designed to analyze shipment, sales, profit, product, location, team, and salesperson performance.

The dashboard transforms business data into interactive visualizations and KPIs to help identify **sales trends, profitable products, high-performing locations, team performance, and shipment patterns**.

---

## 🎯 Project Objectives

* Analyze overall shipment and sales performance
* Track total sales amount and profit
* Identify high-performing products
* Compare performance across different locations
* Analyze team and salesperson performance
* Understand shipment trends over time
* Calculate and analyze profit percentage
* Provide interactive filtering for business analysis
* Present insights through an easy-to-use Power BI dashboard

## 📂 Data Model

The Power BI report contains the following major tables:

* **Shipments** – shipment amount, shipment count, profit and related measures
* **Products** – product information
* **People** – team and salesperson information
* **Locations** – geographical information
* **Calendar** – year and month-based analysis

The model connects these tables to support interactive analysis across different business dimensions.

## 🚀 How to Use

1. Download or clone this repository.
2. Install **Microsoft Power BI Desktop**.
3. Open `powerbi-demo-1.pbix`.
4. Explore the different report pages.
5. Use the slicers and interactive visuals to analyze the data.
6. Select different products, locations, teams, or time periods to explore the results.
